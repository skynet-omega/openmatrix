# Fuentes primarias seleccionadas para la decisión post48

Consultadas el 27-09-2026. Se conservan ocho piezas científicas; artículos, código y datos se distinguen. Algunas aperturas editoriales devolvieron challenge/redirección: cuando ocurrió, se contrastaron pasajes indexados de la propia fuente y evidencia local, sin afirmar lectura integral nueva. Ningún dataset masivo se descargó en esta ronda.

FlyWire/hemibrain hembra, MaleCNS/MANC macho y preparaciones conductuales diferentes requieren correspondencias explícitas.
