# Primera divergencia de eventos aceptados entre motores

**Diagnóstico local cerrado; etapa 3 abierta.** Registramos por bloque de 125 µs cada evento que el propietario físico entregó al filtro KC, con fila, ID, marca, salto y `post_q`. Dos sham de 20 ms usaron el mismo checkpoint, uno con `causal_cuda` y otro con `reference_cuda`. El observador no alteró ni estado CNS, ni trazas, ni contadores frente a los brazos sin observador: diferencias **0** en ambos [controles](NEUTRALITY_CAUSAL.json) y [referencia](NEUTRALITY_REFERENCE.json).

El [primer desacuerdo por bloque](EVENT_COMPARE.json) fue la KC gamma ID **81004**, fila **61131**. El motor de referencia produjo la espiga al final de un bloque; el causal la produjo **3.125 ns después** en el bloque siguiente —es decir, **3,125 µs**, no 3.125 ms—. En el causal aparece dos veces en el informe bruto porque `block_midpoint.py` ejecuta primero una mitad predictora, la restaura, y luego el bloque completo aceptado. Esas dos observaciones corresponden a **una** espiga física aceptada. El total bruto 1564/1563 descompone en **528/527 eventos predictores descartados** y **1036/1036 aceptados**. El [comparador de eventos aceptados](ACCEPTED_EVENT_COMPARE.json) no encuentra diferencia de recuento por neurona entre los 1036 pares; la máxima diferencia temporal es **3.125 ns** (`3125 ns = 3,125 µs`) y la máxima diferencia `post_q` es `2.41e-6`. Estas magnitudes se midieron, no se declararon aceptables a posteriori.

La corrección de ChatGPT para la consulta CPU con SET futuro se incorporó en esta copia aislada de [event_waveform.py](event_waveform.py) y el [fixture](PREFIX_FIXTURE.json) recupera invariancia bit a bit del prefijo. La instrumentación y esta corrección no alteraron las dos trayectorias de 20 ms frente a la campaña anterior. El flujo biológico aún carece de una referencia numérica validada hasta 400 ms; en la comparación corta, el mayor cambio de estado oculto KC entre integradores fue `0,065248`, mientras el estado CNS principal difirió `4,29e-5`. El estado oculto puede afectar eventos futuros aunque la traza motora de 20 ms sea próxima, por lo que no se promueve el motor ni se adjudica etapa 3.
